# Outreach package

Recommended review order:

1. `SignalRoom_Case_Study.pdf` - one-page stakeholder summary.
2. `EMAIL_PROJECT_SNIPPET.md` - concise email paragraph.
3. `DEMO_SCRIPT.md` - three-minute walkthrough.
4. `CASE_STUDY.md` - measured results and limitations.
5. `screenshots/` - representative visuals.

For an initial football-club email, send the PDF and repository URL. Do not attach raw data or describe the historical case as current tactical advice.
