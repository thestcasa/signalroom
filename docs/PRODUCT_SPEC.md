# Product specification

## User and task

The intended reviewer is an opposition or set-piece analyst evaluating a historical example. The bounded task is to identify a recorded corner-delivery tendency, compare it with a preceding window, review several matching examples across matches, inspect recorded roles and outcomes, and write one cautious question.

## Core surfaces

1. Preparation context: team, competition, cutoff, coverage, windows, and modalities.
2. Review shortlist: n/N, match support, percentage-point difference, match-block interval, sensitivity, and suppression reasons.
3. Evidence review: several derived examples with date, opponent, minute, delivery group, roles, outcome, boundary, missing states, and provenance.
4. Peer context: complete-population descriptive comparison when eligible.
5. Export: the exact selected state, notes, evidence references, definitions, provenance, and limitations.

## Required abstention

SignalRoom suppresses a change claim when population, sample, effect, uncertainty, nearby-window direction, evidence, or data quality gates fail. Suppression is quality control, not the product's main value.

## Positioning

SignalRoom is a historical set-piece evidence workbench. It is not club-ready, externally validated, current, predictive, provider-neutral, or a source of tactical prescriptions.
