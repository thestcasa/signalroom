# Historical preparation workflow

1. Select a historical case.
2. Confirm cutoff, fixture coverage, and available modalities.
3. Define one recent window and one preceding reference window.
4. Review recorded corner-delivery group differences and their gates.
5. Open three or more matching derived evidence cards across matches when available.
6. Review an ordinary or unsuccessful example.
7. Record a cautious analyst note or question.
8. Export the exact current state.

The workflow does not infer movement, screens, marking assignments, tactical intent, danger, or causal effectiveness. Visual verification still requires authorized synchronized video.
